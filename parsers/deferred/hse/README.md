# Deferred HSE adapters

These source files are retained for a later expansion. They are not included in
the installable parser package or the active parser registry. The source tree
imports legacy `andromeda.modules.*` and `andromeda.shared.contracts.*`
contracts that are absent from both supplied repositories, so enabling the HSE
adapter now would create an unverified execution path.

The original copies remain unchanged in the `andromeda-parsers` source
repository.

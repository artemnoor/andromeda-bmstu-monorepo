# Страницы образовательных программ

Кнопка «Подробнее» в каталоге открывает `/programs/<code>-<identity-hash>`.
Хеш внешнего ключа сохраняет отдельные адреса у программ с одинаковым кодом.
Возврат в каталог сохраняет его фильтры в истории браузера.

Содержание: описание, направление и кафедра, стоимость, срок и форма обучения,
тип программы; приёмный план и отдельно квоты; экзамены и проходные баллы за
доступный год без графика динамики; отдельно результаты зачисления;
диаграммы категорий и семестров; поиск дисциплин и фильтры семестра/категории.
Выбор категории работает в обе стороны: сектор SVG и строка списка меняют
одно состояние выбора, процент в центре и список дисциплин. Повторный выбор
снимает фильтр. Сектора доступны с клавиатуры (Enter/Space) и имеют точные
области нажатия по форме дуг.
Дисциплины показываются порциями по 30. Неопубликованные сведения не заменяются
предположениями. Подписи сохраняют область действия источника: программа,
направление, предложение, год, кампус. Стоимость направления не называется
стоимостью конкретного кампуса. Квоты не прибавляются к бюджетному итогу.

Данные загружаются через существующие модели admission и comparison с проверкой
единого академического выпуска. Состав плана используется только при однозначно
подтверждённой связи. SVG-диаграмма видна в исходном HTML без JavaScript.

`npm run build` перечисляет каталог и предварительно создаёт HTML и `.data`
всех программ. `scripts/generate-program-sitemap.mjs` добавляет их в собранный
`sitemap.xml`. Публиковать нужно весь `build/client`, включая вложенные папки
`programs` и файлы `.data`. Не ограничивать публикацию корневым `index.html`.

Проверки: typecheck, ESLint, сборка всех страниц; браузерный переход из каталога,
поиск предметов, выбор семестра и категории, «Показать ещё», сравнение, возврат
к фильтрам, прямое открытие и мобильная ширина 390/320 px.

# Обновление профтеста и загрузки экранов — 26.10.2026

Профориентационный тест использует открытую композицию без общей рамки и
подложки. Убраны прежнее вступление и три информационные плашки. Вопросы
разделены на интересы, формат, предпочтения и уточнения. На телефоне варианты
расположены в один столбец, выбор отмечается чекбоксом и цветом. Навигация
остаётся доступной при прокрутке; предусмотрен нижний safe area.

В результатах выделены три основных программы и две альтернативы. В карточке
есть название, кафедра, индекс совпадения и доли интересующих тем. Условия
поступления и происхождение данных раскрываются отдельно. Сохранение ссылки,
PDF, изменение ответов, сравнение и поиск всех программ сохранены. Ссылки
основных рекомендаций ведут на отдельные страницы программ.

Поиск сравнения напрямую использует CSS-модуль каталога и тот же SVG поиска:
одинаковые размеры, типографика, скругление, фокус и оформление подсказок.
Фильтров нет, акцент берётся из страницы сравнения. Добавление сохраняет
прежнюю обработку клика, клавиатуры и закрытия по нажатию вне поля.

`ScreenLoader` — общий компонент ожидания для переходов, начальной загрузки,
сравнения и профтеста. Вращается только тонкая орбита, логотип остаётся чётким.
Быстрые переходы не вызывают вспышку оверлея. Переходы и шаги используют
короткие opacity/translate-анимации без размытия. Учитывается reduced motion.

Проверка: полный тест на телефоне, пять рекомендаций, скачивание PDF и общая
ссылка; поиск и фактическое добавление программы; совпадение геометрии поиска
с каталогом; ширины 320, 390, 768 и 1440 px; проверка axe основного экрана
вопросов без нарушений. Математика рейтинга и данные учебных планов не менялись.

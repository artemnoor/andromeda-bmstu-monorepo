# Поисковая индексация Андромеды

Основной адрес: https://andromedabmstu.ru/. Метаданные маршрутов собраны в `src/shared/seo.ts`: уникальные русские title и description, canonical без параметров, Open Graph, Twitter Card и JSON-LD (WebSite, Organization проекта, WebPage, BreadcrumbList). Организация проекта не выдаётся за университет.

## Сборка и публикация

Дополнение: отдельные страницы `/programs/<code>-<identity-hash>` тоже предварительно
рендерятся из активного каталога. Сборка создаёт для них HTML и `.data`, затем
генерирует расширенный sitemap. Подробности: [PROGRAM_PAGES.md](PROGRAM_PAGES.md).

React Router предварительно рендерит `/`, `/programs`, `/discover`, `/compare`, `/feedback`, `/404`. В HTML есть содержимое страниц без выполнения JavaScript. Каталог получает реальный активный выпуск через build-time loader; первые 12 карточек присутствуют в HTML, остальные добавляются браузером существующими порциями. При гидратации и переходах clientLoader обновляет каталог из API. Фильтры и сохранённые сравнения применяются после гидратации, чтобы их состояние не расходилось с готовым HTML.

`SEO_API_ORIGIN` задаёт адрес API при сборке (по умолчанию основной домен; можно указать IP ВМ или локальный API). Он не задаёт адрес API в браузере. Сборка завершится ошибкой при недоступном или несогласованном каталоге.

После сборки нужно публиковать **весь `build/client`**, включая вложенные HTML и `programs.data`, а не только assets и index.html. Nginx-конфиги в `infra/nginx` обслуживают готовые маршруты, возвращают настоящий HTTP 404 для неизвестных адресов и перенаправляют `/programs/` и `/programs/index.html` на `/programs`. HTML и данные не кешируются надолго, assets с хешем кешируются.

Страницы с поиском/фильтрами, общими сравнениями и результатами теста получают `noindex, follow` через метатег и HTTP-заголовок. Canonical указывает на основной раздел. API, сырые данные и служебные `.data` не предназначены для поиска. `robots.txt` не запрещает загрузку скриптов и изображений.

Иконки создаются из существующего логотипа командой `python scripts/generate-brand-icons.py`: favicon ICO с несколькими размерами, PNG 96, Apple 180, PNG 192/512 и превью 1200×630. Исходный логотип не заменяется. `site.webmanifest` описывает имя и иконки; офлайн-режим не заявляется.

С 23.10.2026 также добавлен рекомендованный Яндексом PNG 120×120; ICO содержит
16/32/48/64/96/120/128/256. Все favicon объявлены в исходном HTML с явными MIME
и размерами. Требования Яндекса: https://yandex.ru/support/webmaster/ru/search-results/favicon.html.
Корректный HTTP 200 не означает немедленного появления иконки в выдаче: база
фавиконок обновляется отдельно. Для ускорения Яндекс рекомендует переобход
главной через Вебмастер. `node scripts/submit-indexnow.mjs --home-only` уведомляет
IndexNow только о главной; успешный ответ не подтверждает обновление фавиконки.

## Проверки

```sh
npm run typecheck
npm run build
node scripts/check-seo.mjs
node scripts/check-seo.mjs --live
```

Проверяются исходный HTML без JS, уникальность заголовков, описания, canonical, H1, реальные карточки каталога, JSON-LD, sitemap, HTTP 404, типы публичных ресурсов и редиректы. В браузере дополнительно проверяются гидратация, фильтр каталога, общая ссылка на сравнение и мобильная вёрстка.

## Уведомление поисковиков

Публичный файл `public/<32-символьный ключ>.txt` подтверждает владение хостом для IndexNow. Это публичное подтверждение домена, а не пароль. После публикации изменённых публичных страниц:

```sh
node scripts/submit-indexnow.mjs
```

Скрипт отправляет URL из sitemap в Яндекс IndexNow. Ответ 200/202 подтверждает получение уведомления; он не подтверждает индексацию или позиции. Не нужно запускать его при каждом открытии сайта.

Для Google Search Console и Яндекс Вебмастера требуется подтверждение домена в аккаунте владельца. При необходимости можно добавить выданную ими TXT-запись в DNS. Sitemap: https://andromedabmstu.ru/sitemap.xml. Старый IP перенаправляет HTML-страницы на основной домен.

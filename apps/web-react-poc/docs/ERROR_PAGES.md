# Страница 404

`src/shared/ui/not-found-page.tsx` — общая страница отсутствующего адреса:
сиреневое SVG «404» с орбитой, сообщение, ссылки на главную и каталог,
профтест и сравнение, обратная связь. Иллюстрация декоративная, без canvas
и сетевых запросов. Утолщённая пунктирная орбита плавно движется через
stroke-dashoffset; при prefers-reduced-motion анимация отключена.
Адаптация проверена на 320/390/768/1440 px.

Компонент используется wildcard-маршрутом, корневой границей ошибок для HTTP 404
и границей отсутствующей программы. Другие ошибки не переименовываются в 404.
Сервер по-прежнему возвращает настоящий статус 404 и не индексирует страницу.
Публиковать вместе с `/404/index.html` и всеми файлами текущей сборки.

Блокировку `main` при открытии меню выполняет существующий AndromedaHeader.
Не дублировать её React-пропом `inert`: при закрытии меню cleanup заголовка
может восстановить сохранённое `true` и заблокировать кнопки.

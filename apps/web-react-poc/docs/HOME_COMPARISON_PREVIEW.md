# Пример сравнения на главной

Блок «Всё для осознанного выбора направления» использует фиксированный компактный пример из `src/features/home/data/comparison-preview.json` (schemaVersion 2). В браузере нет запросов к базе знаний, проверки выпуска, восстановления Map/Set и расчёта учебных планов. Числа, названия, часы и публичные ссылки на источники сохранены из проверенного сравнения программ ИУ9 и ФН11. Данные примера обновляются при явном запуске генератора и публикации сайта.

Генератор заранее рассчитывает четыре строки учебной матрицы, ячейки таблиц приёма и SVG-контуры диаграмм. Вместо полного снимка на 458 787 байт браузер получает модель на 17 019 байт. На главной больше не загружается Recharts; диаграммы представлены встроенными SVG с выбором категории мышью или клавиатурой. Обычная страница сравнения продолжает работать с актуальными данными и своими компонентами.

Сохранены наклон, глубина, масштабирование, перетаскивание и параллакс CardSwap. CSS zoom и исходная перспективная проекция в 2D сохраняют размер и расположение текста. Четыре карточки постоянно смонтированы, а их JSX не создаётся заново на каждом переключении. Отдельные слои и CSS containment ограничивают перерисовку; атрибуты доступности меняются только при смене передней карточки. Анимация и автопереключение приостанавливаются за пределами экрана и в скрытой вкладке.

На телефонах до 600 px вся колода остаётся inert: доступно только автоматическое перелистывание. На компьютерах и планшетах сохраняются взаимодействие, прокрутка таблиц и выбор категорий. prefers-reduced-motion отключает автопереключение. Активная карточка сохраняется в sessionStorage при переходах между страницами.

Мобильная карточка имеет виртуальный размер 600 × 600 вместо широкого 840 × 500. Примеры таблиц показывают две полные строки и обе программы рядом; заголовки сокращены до кода программы и кафедры, а длинные пояснения ограничены двумя строками. Учебная матрица показывает первую позицию каждой дисциплины. Обе SVG-диаграммы помещаются целиком с названиями программ и общей подписью категории. Полный набор сведений остаётся на странице сравнения.

Обновление фиксированного примера из проверенных данных:

```powershell
$env:ACADEMIC_DATA_API_ORIGIN = 'http://185.135.175.229'
npm run home:preview-snapshot
npm run build
```

Генератор проверяет выпуск, полноту двух планов, классификации и данные приёма перед записью. Параметр `--from-snapshot` предназначен для однократной конвертации старого полного снимка schemaVersion 1.

Для воспроизведения измерения в браузере используется `output/playwright/measure-showcase.cjs`: четыре переключения за 8,2 секунды при CPU slowdown 4×, с остановленными CSS-анимациями окружения. В выполненном сравнении старая версия дала 27 кадров >33,4 мс, новая — 0. Это измерение в тестовом Chromium, а не гарантия FPS на всех устройствах.

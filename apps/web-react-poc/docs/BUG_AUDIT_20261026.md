# Проверка сценариев сайта — 26 октября 2026

## Исправлено

1. Повреждённая ссылка `/compare?program=bad` интерпретировалась как намеренно пустой общий выбор. Эффект записывал пустой список в localStorage и удалял ранее выбранные программы. Теперь некорректные параметры используют сохранённый выбор и показывают уведомление. Валидная пустая ссылка `shared=1` по-прежнему открывает пустое сравнение. Некорректные, повторяющиеся флаги `shared`, пустые идентификаторы и превышение лимита также отклоняются.
2. Переход на `/discover?result=bad!` сбрасывал сохранённый результат профтеста. При ошибке разбора ссылки восстановление теперь возвращается к действительной сессии этого выпуска. Уведомление поясняет, что восстановлены именно собственные ответы пользователя. Проверка версии выпуска остаётся обязательной; чужие ответы из повреждённого содержимого не используются.
3. Программы без подтверждённого учебного плана в результатах профтеста вели в отфильтрованный каталог. Теперь ссылка ведёт на отдельную страницу с точной идентичностью программы, как и у остальных результатов. Это также различает программы с одинаковым официальным кодом.
4. Автопрокрутка восстановленного результата прятала сообщение о повреждённой ссылке под фиксированной шапкой на телефоне. При открытии результата по ссылке автоматический переход к карточкам отключён: пояснение о результате видно сразу. Обычное завершение теста сохраняет прежнюю прокрутку.

Каждая ошибка воспроизведена на опубликованном сайте до изменения кода. Один и тот же браузерный сценарий повторён после исправления: сохранённые программы и сериализованная сессия остаются прежними, результат восстанавливается, ссылка ведёт в `/programs/<slug>`.

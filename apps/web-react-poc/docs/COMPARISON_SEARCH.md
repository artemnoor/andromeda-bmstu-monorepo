# Поиск программ в сравнении

`ProgramPicker` показывает поиск прямо на `/compare`, включая пустое сравнение.
Используется активный каталог, существующая нормализация программ и поисковый
индекс по названию, коду направления, профилю и кафедре. Отображаются первые
семь результатов с предложением уточнить запрос. Поиск локальный, без запросов
к API на каждое нажатие клавиши.

Добавление вызывает существующий `updateSelection`: для сохранённого выбора
обновляется localStorage, для общей ссылки также обновляется URL. Выбранные
программы отмечены текстом и галочкой. Четвёртая не добавляется, показывается
существующее уведомление с красной рамкой. Доступны очистка поиска, повтор
загрузки, сообщение об отсутствии результатов, ArrowUp/ArrowDown, Escape,
Tab и Enter. Поле имеет видимую подпись; на телефоне размер текста 16px.

После добавления запрос сохраняется, строка получает отметку «В сравнении».
Выдача закрывается по pointerdown вне компонента или Escape, но не по blur:
смена фокуса между pointerdown и click иначе удаляет кнопку до обработки выбора.
Для Escape отменяется стандартная очистка input[type=search], чтобы событие
очистки не открывало выдачу повторно. Проверка регрессии: нажать кнопку мыши
на результате, перевести фокус на main, отпустить кнопку — программа добавляется.

Иконки в подвале используют исходные локальные SVG как CSS-маски: исходный цвет
белый, hover и focus-visible плавно меняют его за 240ms, без трансформации и
подложки. Telegram — #26A5E4, ВКонтакте — #0077FF. При reduced motion переход
отключён. Проверены неизменность координат при наведении, реальные вычисленные
RGB-значения, поиск, добавление трёх программ, лимит, общая ссылка и клавиатура.

## Исправления

- API возвращает семестровые часы как `hours`, общие часы дисциплины остаются
  отдельным `total_hours`. Аналогично разделены показатели видов занятий.
- Каталог, сравнение, PDF и профтест суммируют семестровые показатели.
- PDF разбирается по координатам подколонки «з.е.», включая шаблоны на 8,
  12 и 14 семестров. Бывшее ограничение 12 семестрами снято.
- Факультативы, дополнительные адаптивные дисциплины и физкультура без з.е.
  отделены от основной программы. В карточке есть отдельный список.
- Физкультура относится к общей категории «Физическая культура и спорт» и
  исключена из весов профессиональных интересов. Нераскрытые группы дисциплин
  по выбору тоже не получают выдуманную профессиональную специализацию.
- Новая публикация хранит исправленные факты и ссылки на PDF. Предыдущий
  выпуск сохраняет исходные данные. Прежние AI-предсказания переиспользуются
  для той же дисциплины той же программы с явным происхождением; переносы на
  восстановленные семестровые строки помечены `needs_review`. Новых AI-вызовов нет.
- Если основной итог при следующем разборе не сходится с PDF, план требует
  проверки и не считается успешно разобранным.

Профильные снимки профтеста и демонстрация на главной пересоздаются по
исправленному выпуску. Если в PDF нет полного семестрового распределения по
видам занятий, этот сигнал не используется в рейтинге; общие часы дисциплины
не подставляются вместо отсутствующих семестровых значений.

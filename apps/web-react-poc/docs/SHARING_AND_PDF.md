# Ссылки на сравнение, результат профтеста и PDF

В сравнении и в результатах профтеста есть отдельные действия «Получить ссылку» и «Скачать PDF». Работа не требует регистрации или сервера хранения файлов.

## Сравнение

`/compare?shared=1&program=<external_key>&program=<external_key>` принимает до трёх устойчивых ключей программ. Порядок сохраняется. При открытии ссылка имеет приоритет над прежним выбором в localStorage; если запись в хранилище запрещена, просмотр по URL продолжает работать. Выбор также сохраняется локально для дальнейших переходов по сайту. Удаление программы обновляет URL. Обычный `/compare` продолжает использовать сохранённый выбор.

Ссылка фиксирует состав программ, а данные читает из активного академического выпуска. Неизвестные ключи не заменяются похожими программами. PDF сохраняет значения на момент скачивания, дату, источник и идентификатор выпуска.

## Профориентационный тест

`/discover?result=<base64url JSON>` содержит версию формата, ключ академического выпуска и ответы. Перед восстановлением проверяются размер, допустимые категории, формат занятий, сравнения и совпадение выпуска. Результат заново вычисляется по тем же ответам и профилям. При несовпадении выпуска показывается объяснение и предлагается пройти тест по актуальным данным.

Ответы видны любому, кому передана ссылка. Имя, баллы ЕГЭ и содержимое локального профиля в неё не включаются. Кнопки редактирования и нового прохождения удаляют параметр результата; история ответа восстанавливается в совместимом с сессией формате.

Рядом есть «Сравнить рекомендации»: переход открывает три основных рекомендации, независимо от прежнего выбора. В PDF результата включены предпочтения, пять лучших программ с индексом совпадения и подробное сравнение трёх основных рекомендаций. Индекс не является вероятностью поступления.

## PDF

Файл создаётся в браузере через динамически загружаемые jsPDF и jsPDF-AutoTable. Шрифты Noto Sans с кириллицей загружаются с того же сайта только по запросу экспорта. Текст можно выделять и искать; таблицы разбиваются на страницы, источники и ссылка на результат кликабельны.

В отчёте используются те же модели баллов и зачисления, что и на странице: БВИ, неполные данные и область применимости показателя не заменяются произвольными числами. Компактный макет включает карточки программ, векторные круговые диаграммы с общей легендой, таблицу «Часы по категориям» с цветами диаграмм и итогами, график часов по семестрам, краткие таблицы поступления и кликабельные источники. В результатах профтеста добавлена первая страница с предпочтениями и полосами совпадения для рекомендаций. Полные описания и длинная таблица дисциплин доступны на сайте по ссылке внизу каждой страницы. На проверенных примерах сравнение занимает 6 страниц вместо 22, результат профтеста — 7 вместо 17. Число страниц зависит от длины названий, условий поступления и количества семестров; текст не обрезается ради фиксированного лимита.

Копирование использует Clipboard API, а на HTTP — доступный браузеру способ копирования выделения. Если браузер блокирует копирование, ссылка остаётся в поле для ручного выделения.

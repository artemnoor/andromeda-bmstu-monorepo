## Главная и производительность

Перед подвалом добавлена секция с фирменным знаком и орбитами. Поворот орбит и появление заголовка зависят от прокрутки через нативный CSS view timeline; постоянных JavaScript-обработчиков прокрутки нет. Для старых браузеров — однократный переход по IntersectionObserver, для reduced-motion — статичная версия. У body используется overflow-x: clip, чтобы промежуточный не прокручиваемый контейнер не перехватывал view timeline.

Слой текстуры уменьшен с 300×300% до 120×120%: его площадь составляет 1,44 экрана вместо 9. На мобильных текстура неподвижна. Карточки сохраняют прежние наклон, масштаб, интерактивность на компьютере и автоматическое перелистывание на телефоне. Содержимое закрытых задних карточек не рисуется; исходящие карточки сохраняют содержимое до завершения движения. Для этого используется visibility, сохраняющая геометрию таблиц. Интервал автоперелистывания — 6 секунд, чтобы уменьшить постоянную анимационную нагрузку и дать время прочитать пример. Предварительная загрузка блока ограничена 320 px до его появления.

График нагрузки по семестрам вынесен в отдельный lazy-модуль. Основной JS-блок сравнения уменьшился с 419,73 до 336,71 kB, gzip с 122,06 до 102,51 kB. Отдельный модуль графика — 87,34 kB (23,05 kB gzip), загружается при показе сравнения. Круговые диаграммы остаются в основном блоке. Анимация баров отключена, интерактивные подсказки сохранены.

Контрольный сценарий производительности: Chromium, CPU ×4, 9 секунд в видимом блоке карточек, отдельно 390 и 1440 px. Исходный и итоговый JSON находятся в output/polish-20261026. Это синтетический сценарий, не оценка FPS физических телефонов. Промежуточный вариант с content-visibility вызывал повторную раскладку таблиц; в окончательной версии он заменён visibility.

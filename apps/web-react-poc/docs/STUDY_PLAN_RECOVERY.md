# Восстановление загрузки учебных планов — 19.10.2026

## Причины и результат

Проверены все 25 программ без загруженного плана, а не только пример
27.03.05/09. Их ссылки ведут на семь разных публичных ресурсов.

| Результат проверки официального источника | Программ |

| Восстановлен точный план 01.03.04-05, ФН2 | 1 |
| DOCX-заглушка «Учебный план появится позже» | 14 |
| Публичная папка действительно пуста | 4 |

Для 27.03.05/09 официальный каталог возвращает `https://clck.su/ltLsG`.
Ссылка раскрывается в `https://disk.yandex.ru/d/fwATDcEck-9Xsg`.
Единственный PDF содержит профиль **27.03.05-10 «Управление промышленными
инновациями»**, а не «Технологическое продюсирование в креативных индустриях».
Пользователь подтвердил, что ошибся насчёт наличия отдельного плана /09.
Чужой состав дисциплин к /09 не привязан.

У 01.03.04-05 файл доступен. Длинный заголовок профиля переносится на следующую
строку; старый парсер искал код только на первой. Исправление восстановило
точный код и полное название, 113 строк дисциплин и год начала обучения 2026.

## Общие изменения

- Загрузка всех страниц и вложенных папок Яндекс Диска; получение download URL,
  когда метаданные файла не содержат готового `file`.
- Ограничения: 64 дополнительных запроса метаданных, глубина папок 6,
  по умолчанию максимум 64 скачиваемых документа. Существующие ограничения
  времени, размера ответа и разрешённых хостов остаются в силе.
- Продолжения заголовка PDF читаются только до следующего поля шапки.
- Новый `python -m andromeda_parser.repair_study_plans INPUT OUTPUT` повторно
  проверяет все незагруженные планы, кэширует общие ссылки, создаёт новый
  неопубликованный пакет и отдельный JSON-отчёт. Исходный пакет не изменяется.
- Только уникальный PDF с точным кодом профиля, разобранными строками и
  однозначными идентификаторами может восстановить план. Совпадение только
  направления или наличие общей ссылки недостаточно.
- Сохраняются SHA-256, время получения и ссылка на источник; причины отсутствия
  данных обновлены. Сравнение различает заглушку, пустую папку и чужой профиль.

Живая проверка выявила дополнительную причину HTTP 500: составной ключ
`source_evidence` для новой дисциплины длиннее 256 символов. БД и mapper уже
поддерживают 512. Лимит **только `SourceEvidenceReference.evidence_key`** приведён
к 512; ключи программ не менялись. OpenAPI пересоздан, TypeScript-типы
сгенерированы из него. Схема PostgreSQL не изменялась.

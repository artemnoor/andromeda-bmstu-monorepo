# Проф-тест: понятность и доступность результатов

Дата: 12 октября 2026. Страница: `/discover`.

## Что изменено

- Вместо названий классификатора на этапе вопросов — понятные занятия и примеры: «Программировать», «Защищать информацию», «Заниматься дизайном». Пояснения привязаны к точному названию категории; неизвестный классификатор не переименовывается по совпавшему коду.
- Показаны этапы, возможность передумать и сохранение ответов в текущей вкладке. Вариант «Пока трудно выбрать» доступен до длинного списка интересов. Вопрос о нежелательных темах можно пропустить.
- Парные вопросы объясняют выбор первого/второго занятия. «Одинаково» означает отсутствие предпочтения, а не добавление интереса к обеим областям.
- Результат объясняет предпочтения пользователя и доли тем в реальном учебном плане. Подробности классификации и оригинал источника раскрываются отдельно. Альтернативы не называются близкими без оснований.
- Добавлены полный список результатов, поиск по названию/коду/направлению/кафедре и быстрый переход к поиску. Первоначально показаны 12 строк, остальные раскрываются порциями. После раскрытия фокус переходит к первой новой программе.
- Нейтральные ответы позволяют просматривать каталог без выдуманной персональной оценки. Программы без подтверждённого плана доступны отдельно без балла совпадения.
- Увеличены подписи, сохранены клавиатурное управление и видимый фокус. Исправлены недостаточный контраст разделителя пар, размещение результата под фиксированным хедером и переполнение длинных названий при ширине 320 px.
- Исправлена гонка восстановления фокуса общей навигации. Проверка домашнего меню использует актуальный CSS-класс общего хедера. Для прохождения общего ESLint синхронизация параметров фонового шейдера перенесена из render в effect.

## Можно ли получить все направления

На подключённом академическом выпуске каталог содержит **152 программы**. Для **127** доступны подтверждённые профили учебных планов; для **25** такого профиля нет.

Раньше интерфейс показывал только первые три рекомендации и две альтернативы. Теперь все 127 результатов доступны в списке и поиске независимо от позиции. Ещё 25 программ можно найти и открыть в каталоге, но им не назначается недостоверная оценка. Добавление в сравнение использует точный `external_key`, сохраняет ограничение в три программы и сообщает об ошибках browser storage.

Живая проверка Chromium прошла весь тест, нашла **каждый из 152 кодов**, раскрыла все 127 строк и отдельно 25 программ без оценки. API каталога вернул один `release_key`:

`bmstu-2026:42616ee9348ee009fa1b297f7ef697862134835e562c7840f413643ce71d2130:bmstu-2026-bundle-v4`.

Независимый аудит выполнил **10 000** воспроизводимых сценариев реальной модели с seed `271828`, действительными ограничениями выбора, адаптивными парами и досрочным завершением. Каждый сценарий сохранял все 127 профилей в полном результате.

| Первые позиции | Разных программ, наблюдавшихся в выборке |
|---|---:|
| 1 | 78 |
| 3 | 110 |
| 5 | 116 |
| 10 | 123 |
| Полный список | 127 |

Из 52 кодов направлений с профилями в первой тройке наблюдались 49. Это **нижние границы по выборке**, а не доказательство недостижимости остальных вариантов. Не утверждается, что любая программа обязательно попадёт в первую тройку. Доступность всех результатов обеспечивается полным списком и поиском.

## Проверка подбора и данных

- Все 16 сценариев с одним интересом проходят настоящее адаптивное завершение и сохраняют все 127 профилей.
- Проверены ожидаемые направления после завершённого сценария: программирование → `09.03.04`, информационная безопасность → `10.05.03`, дизайн → `54.03.01`, экономика → `38.03…`.
- Сохранены проверки программ ИБМ, числовой корректности профилей, классификации и отсутствия выдуманного плана для программы без подтверждённого источника.
- Формула ранжирования, веса, учебные часы и академические связи не менялись. Изменены формулировки парных ответов, но сохранены их значения `−2…2`.
- Регрессии проверяют переключение выпуска при загрузке планов, несовпадение выпуска snapshot, переключение после чтения и неподдерживаемую схему. Несогласованные данные не превращаются в успешный результат.
- Проверены нейтральные ответы, пропуски, ограничения выбора, возврат назад, обновление страницы, повторное открытие маршрута, сброс, API retry, отмена при уходе, невалидные экзаменационные баллы и отклонённая запись browser storage.

## Независимая проверка

Субагент `prof_test_reachability_audit` отдельно исследовал охват модели и проверил итоговые компоненты только для чтения. Замечания об обещании «близких» альтернатив и фокусе после раскрытия списка исправлены. Финальный аудит не обнаружил конкретных P0/P1 или существенных P2.

## Воспроизведение

Из `apps/web-react-poc`:

```powershell
npm run typecheck
npm run lint
npm run test
node scripts/audit-prof-test-reachability.mjs
node scripts/check-prof-test-usability.mjs
```

Последний скрипт использует уже работающий сайт на `http://127.0.0.1:4180` и его API. Для другого адреса задаётся `PROF_TEST_BASE_URL`. Он создаёт отдельный контекст Chromium и не меняет серверные данные или пользовательскую сессию.

Для browser regression с отдельным production preview, когда локальный сайт уже проксирует работающий API:

```powershell
$env:PLAYWRIGHT_WEB_PORT = '4182'
$env:API_PROXY_TARGET = 'http://127.0.0.1:4180'
$env:PLAYWRIGHT_JSON_OUTPUT_NAME = 'output/playwright/prof-test-usability/browser-results.json'
npx playwright test tests/e2e/prof-test.spec.ts tests/e2e/home-navigation.spec.ts tests/e2e/site-usability.spec.ts '--reporter=list,json'
```

Детали выборки, хеши исходников и лучшие наблюдавшиеся позиции каждой программы: `benchmarks/prof-test-reachability.json`. Живая проверка: `output/playwright/prof-test-usability/live-validation.json`.

## Ограничения

Это подбор по содержанию учебных планов, а не оценка способностей или прогноз зачисления. Отсутствие подтверждённого плана у 25 программ остаётся ограничением данных. Автоматизированная доступность не заменяет исследования с реальными абитуриентами и пользователями экранных дикторов. Формула подбора не подкручивалась ради заранее желаемого победителя; проверка релевантности и доступ к полному каталогу отделены от обещания попадания в top3.

# Web application boundary

No web frontend, browser bundle, client-side router, or web deployment is
configured in this repository. The existing API is a read-only HTTP interface;
Directus is an optional internal data viewer, not a custom web application.

A future web client needs its own product, accessibility, authentication,
API-versioning, and deployment design. Keep frontend secrets out of browser
code and do not describe this placeholder as an available application.
